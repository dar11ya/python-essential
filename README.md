#  Python Essential (Python Базовий)

Конспекти та розв'язані завдання з курсу **Python Базовий** — продовження курсу
[Python Starter](https://github.com/dar11ya/python-starter).

На цьому курсі я вивчаю об'єктно-орієнтоване програмування в Python, рекурсію,
структури даних, модулі, роботу з файлами та правила оформлення коду.

## План і прогрес

| Статус | Файл | Тема |
|:------:|------|------|
| ✅ | [`01_classes_and_objects.py`](01_classes_and_objects.py) | введення в ООП: класи, екземпляри, `__init__`, `self`, методи, атрибути класу, `@classmethod`, `@staticmethod` + домашні завдання (`Order`, `Book`, `BankAccount`) |
| ⬜ | `02_inheritance.py` | спадкування: батьківські та дочірні класи, множинне спадкування |
| ⬜ | `03_encapsulation.py` | інкапсуляція: обмеження доступу до атрибутів і методів |
| ⬜ | `04_polymorphism.py` | поліморфізм та інтерфейси |
| ⬜ | `05_abstraction.py` | абстракція: загальні характеристики та функціонал класу |
| ⬜ | `06_recursion.py` | робота з рекурсією |
| ⬜ | `07_data_structures.py` | структури даних |
| ⬜ | `08_modules.py` | стандартні модулі та створення власних |
| ⬜ | `09_files.py` | читання та запис файлів: текстові, XML, CSV, JSON |
| ⬜ | `10_paradigms_and_code_style.py` | парадигми програмування, PEP 8, PEP 20 |

✅ — готово, ⬜ — ще попереду. Файли з'являтимуться в репозиторії по мірі проходження курсу.

## Як користуватися

Щоб запустити будь-який приклад:

```bash
python 01_classes_and_objects.py
```

Більшість прикладів закоментовано, бо я запускала їх по одному під час навчання.
Розкоментуйте потрібний блок (у PyCharm: виділити код і `Ctrl + /`, на Mac `Cmd + /`) і запустіть файл.
